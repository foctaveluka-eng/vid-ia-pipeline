## 1. FONDATIONS ALGORITHMIQUES

### Comment l'algorithme YouTube Shorts décide du viral

```
Publication → 500 impressions test (1h)
  ↳ Swipe away rate < 35% ?    → Pousse à 2000 impressions
    ↳ Completion > 45% ?        → Pousse à 10 000
      ↳ Like/Share/Commente > 5% ? → Pousse à 100 000+
        ↳ Boucle vertueuse      → VIRAL
```

### Les 3 métriques qui comptent VRAIMENT

| Métrique | Cible | Impact |
|---|---|---|
| **Swipe Away Rate** | < 30% | **#1** — Si les gens swipe, t'es mort |
| **Completion Rate** | > 45% | **#2** — L'algo veut des vidéos vues jusqu'au bout |
| **Engagement Rate** | > 8% | **#3** — Commentaires + Partages = multiplicateur |

### Notre promesse algorithmique

Chaque vidéo produite par ce pipeline est CONÇUE pour :
- **Swipe away < 30%** grâce aux hooks millimétrés (0-2s)
- **Completion > 45%** grâce aux pattern interrupts toutes les 3s
- **Engagement > 8%** grâce au comment-bait engineering

## 2. ARCHITECTURE DES 4 FORMATS

### 🍎 DESSIN ANIMÉ — Verger Magique
```
Créneau : Matin 06h-12h | Durée idéale : 18-35s (sweet spot: 25s)
Public : Enfants 6-12 ans + parents qui supervisent
Hook : Curiosité 60% + Rire 30%
```

### Le pattern universel qui marche sur tous les formats

```
Rétention %
│
100% ┤ HOOK ───┐
│              │
80%  ┤         └── SETUP ───┐
│                            │
60%  ┤                       └── ESCALADE ───┐
│                                            │
40%  ┤                                       └── TWIST ───┐
│                                                          │
30%  ┤                                                     └── RÉSOLUTION ──┐
│                                                                             │
20%  ┤                                                                            └── CTA
│
└─────┬──────┬──────────┬──────────┬──────────┬──────────┬──────────┬─────▶ Temps
      0s     3s         7s        12s        16s        20s        24s
      HOOK   SETUP      BEAT      TWIST      PAYOFF     CTA        FIN
```

### Règles ABSOLUES de rétention

1. **Hook à 0s** : pas d'intro, pas de logo, pas de "salut les amis" — ON COMMENCE FORT
2. **Pattern interrupt toutes les 3s** : changement visuel ou sonore pour reset l'attention
3. **Twist à 70%** du temps : le moment le plus partageable
4. **Finir sur une question** : pas de "merci d'avoir regardé"
5. **Durée TOTALE** : jamais plus de 35s (sauf manga exceptionnel)

## 5. PATTERN INTERRUPTS SYSTEM

### Pourquoi ça marche

Le cerveau humain s'habitue à tout en 3 secondes. Si rien ne change, le spectateur swipe. **Chaque 3s, tu DOIS casser le pattern.**

### Notre arsenal d'interrupts

```
VISUELS (toutes les 3s) :
├── Changement de cadrage (wide → close-up → extreme wide)
├── Zoom avant rapide (1.5x en 0.3s)
├── Changement d'angle (plongée → contre-plongée)
├── Passage jour/nuit
└── Split screen

AUDIO (toutes les 4-5s) :
├── Beat drop (silence → reprise plus forte)
├── Changement de ton (normal → whisper → cri)
├── Effet sonore percutant
└── Silence de 0.5s

NARRATIFS (tous les 2-3 segments) :
├── "Et là... j'ai compris."
├── Question rhétorique au spectateur
├── Flashback rapide
└── Briser le 4e mur
```

## 6. COMMENT-BAIT ENGINE

### Les 3 techniques qui marchent

### 🔥 Technique #1 : POLARISATION
Forcer un choix entre deux camps. Personne ne peut rester neutre.

```
"Team Mika ou Team Ilyan ? Dis en commentaire !"
"Plutôt d'accord avec le gouvernement ou les opposants ?"
"Tu aurais ouvert la porte ou tu aurais fui ?"
```

### 💎 Technique #2 : DÉFI / SONDAGE
Demander une action SIMPLE qui donne l'impression de participer.

```
"Si ça t'est déjà arrivé, mets 🔥 en commentaire !"
"Tague quelqu'un qui DOIT voir ça !"
"Mets 🔔 si tu veux la suite avec les sources !"
```

### 🎯 Technique #3 : FOMO (Suite Promise)
Créer une peur de manquer le prochain épisode.

```
"La suite arrive DEMAIN — et c'est encore PIRE. Active la cloche ! 🔔"
"Je poste la partie 2 que si on atteint 100 commentaires !"
"Le chapitre {next} = le PLUS CHOQUANT. Abonne-toi !"
```

### Règle d'or du CTA
1. **Question** (force la réponse)
2. **Incitation abonnement** (FOMO)
3. **Émoji** (visuel)

En un segment : "Et toi, t'aurais fait quoi ? Dis en commentaire ! Abonne-toi pour la suite demain ! 🔥"

## 11. PLAN D'EXÉCUTION 30 JOURS

### Semaine 1 : Foundation
```text
J1-J3  : Publier 1 vidéo/jour (n'importe quel format)
J4-J7  : Publier 2 vidéos/jour (test des créneaux)
       - Matin (8h) + Soir (22h)
       - Analyser quel créneau performe
```

### Semaine 2 : Optimisation
```text
J8-J14 : 2-3 vidéos/jour au meilleur créneau détecté
       - Tester différents types de hooks
       - Analyser les commentaires pour améliorer le CTA
       - Ajuster les durées selon la rétention
```

### Semaine 3 : Scale
```text
J15-J21 : 3 vidéos/jour (stabilisation de l'algo)
         - Doubler les formats qui marchent
         - Arrêter les formats qui ne marchent pas
         - Publier aux 3 meilleurs créneaux
```

### Semaine 4 : Viral Hunt
```text
J22-J30 : Identifier la vidéo qui a le mieux marché
         - Créer 3 variantes avec des hooks différents
         - Publier aux heures de pointe
         - Utiliser le trend jacking automatique
         - Lancer une série spéciale (Halloween si octobre)
```

### Règle des 30 jours
> Si après 30 jours aucune vidéo n'a dépassé 10 000 vues, on revoit la stratégie de A à Z.
> Si une vidéo dépasse 50 000 vues, on DOUBLE le même format le lendemain.
